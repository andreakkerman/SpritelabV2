# Mobile workflow

1. In Safari, load Assets from Files or Photos. Confirm every required row reports dimensions and alpha.
2. Start in whole-leg mode. Tap a leg, drag its gold pivot onto the hip, and use the large rotation/position controls.
3. Build poses `00` through `07`; playback remains available above the controls at all times.
4. Cycle onion skin through previous, next, and both. Tune opacity to see foot contacts without obscuring the active pose.
5. Use frame-specific forward/backward controls for crossing legs. Use “Mirror opposite legs” as a helper, then refine manually.
6. Pinch the stage to zoom. Pan by dragging a locked layer or empty/stable stage region; tap **Fit** to recover the default view.
7. Watch “Saved on this device,” but download project JSON and a complete ZIP before clearing Safari data or moving devices.
8. Export ZIP. If iOS offers Share, save to Files or AirDrop it. If not, Safari uses a normal Blob download; individual exports are the fallback.

Upper body and pelvis cover are locked. The advanced unlock warning allows bind-position correction, but frame animation of stable artwork remains invalid.
